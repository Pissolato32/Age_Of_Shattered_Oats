## 1. Objetivo

Definir a arquitetura formal, contratos tipados, fronteiras de segurança e tratamento de falhas para a **Camada Narrativa (M18.9-D)** dos Incidentes Emergentes e Microcenas de *Age of Shattered Oaths*.

A camada narrativa atua estritamente como um **Pós-Processador Sensorial** (Iron Chronicle Post-Processor), transformando fatos mecânicos secos e determinísticos já computados pelo motor em crônicas narrativas imersivas e viscerais.

---

## 2. Estado Atual do Repositório

O repositório possui uma base mecânica 100% determinística consolidada:
- `src/domain/events/models.ts`: Define os tipos canônicos de eventos (`EventRecord`, `EventMutation`, `SceneState`, `SceneChoice`, `TimeCost`).

## 4. Fronteira Mecânica / Narrativa

### 4.1 Fatos Mecânicos Autorizados para Envio (Leitura Permitida)
Os seguintes dados já computados pelo motor podem ser informados ao tradutor sensorial:
- **Identidade e Tipo do Incidente:** `eventType`, `magnitude`, `domain`, `locationId`.
- **Impacto Material Concreto:** Descrições textuais das mutações aplicadas (ex: "50 moedas de prata deduzidas para reparos", "1 operário ferido").
- **Opções de Cena Apresentadas:** Título e descrição temática de cada `SceneChoice` disponível.
- **Escolha Realizada:** `choiceId`, label da escolha selecionada e suas consequências concretas computadas.
- **Contexto Sensorial Local:** Região, clima vigente, estação do ano, fortificação atual, lista de conselheiros presentes na comitiva.

### 4.2 Dados Proibidos de Envio como Instruções Mutáveis
- Métodos do motor, callbacks, ponteiros de função.
- Estado bruto mutável de `CampaignState` (o modelo recebe apenas projeções de leitura).
- Tokens secretos de validação, chaves criptográficas, hashes internos do `EventStore`.

### 4.3 Sanitização Obrigatória na Saída Narrativa
- **Silêncio Mecânico:** A prosa narrada não deve conter jargões de RPG (como `+10 SD`, `-5 FSU`, `AC 3`, `DC 15`, `roll 18`, `Status ACCEPTED`). Toda perda ou ganho material deve ser traduzida em impacto físico ("o tilintar das moedas de prata deixando os baús de ferro", "os fardos de trigo mofando no canto úmido").
- **Proibição de Metalinguagem:** Proibido o uso de termos como "Engine", "Mestre", "Regras", "Causalidade", "EventRecord".

## 5. Contratos Propostos para o M18.9-D

```typescript
/**
 * Fatos mecânicos autorizados resultantes da resolução do motor.
 */
export interface MechanicalFacts {
  readonly eventId: string;
  readonly eventType: string;
  readonly magnitude: 'INCIDENTAL' | 'MINOR' | 'SIGNIFICANT' | 'MAJOR' | 'CRITICAL';
  readonly domain: string;
  readonly absoluteTurn: number;
  readonly timeCostSummary: string;
  readonly mutationsSummary: readonly string[];
  readonly resolutionEventId?: string;
  readonly choiceMade?: {
    readonly choiceId: string;
    readonly label: string;
    readonly outcomeSummary: string;
  };
}

/**
 * Contexto sensorial e cênico permitido para ambientação.
 */
export interface DescriptionContext {
  readonly locationName: string;
  readonly regionName: string;
  readonly seasonName: string;
  readonly weatherDescription: string;
  readonly holdingType: string;
  readonly presentAdvisors: readonly Array<{ readonly name: string; readonly role: string }>;
  readonly atmosphereTags: readonly string[];
}

/**
 * Opções de cena apresentadas ao jogador para tradução estética.
 */
export interface NarrativeChoicePrompt {
  readonly choiceId: string;
  readonly label: string;
  readonly descriptiveHint: string;
}

/**
 * Payload estruturado enviado ao adaptador sensorial.
 */
export interface IncidentNarrativeRequest {
  readonly kind: 'INCIDENT_OPENED' | 'INCIDENT_RESOLVED' | 'ATMOSPHERIC_INCIDENT';
  readonly mechanicalFacts: MechanicalFacts;
  readonly context: DescriptionContext;
  readonly availableChoices?: readonly NarrativeChoicePrompt[];
}

/**
 * Resposta textual da camada narrativa.
 * Não contém nenhuma estrutura de dados executável ou mutacional.
 */
export interface IncidentNarrativeResponse {
  readonly narration: string;
  readonly promptChoicesFormatted?: readonly {
    readonly choiceId: string;
    readonly formattedText: string;
  }[];
  readonly source: 'GEMINI' | 'PROCEDURAL_FALLBACK';
}
```

## 6. Fluxo de Dados e Ciclo de Vida

1. **Geração do Incidente:**
   - Durante `resolveWeeklyTurn`, o `EmergentIncidentPipeline` seleciona e cria o `EventRecord`.
   - Se o incidente abrir uma cena (`SceneState OPEN`), o motor pausa o avanço semanal e registra a cena em `sessionLog.activeScene`.
2. **Tradução Sensorial da Cena Aberta:**
   - O controlador invoca `NarrativeSceneTranslator.translateIncidentOpened(eventRecord, state)`.
   - O tradutor extrai os `MechanicalFacts` e o `DescriptionContext`, enviando o prompt ao `GeminiNarrativeLLM`.
   - Em caso de falha de rede/timeout, ativa o `ProceduralFallbackTranslator`.
   - A narrativa gerada é apresentada na UI do jogador com as opções fechadas.
3. **Decisão do Jogador:**
   - O jogador escolhe uma das opções fechadas (`choiceId`).
   - A escolha é enviada ao endpoint de resolução (`/api/events/resolve-scene`).
4. **Resolução Mecânica Canônica:**
   - `SceneResolver.resolveSceneChoice` valida a escolha, gera o `resolutionEvent` com `causalParentEventId` e o `EventProcessor` aplica as mutações atomicamente no `CampaignState`.
5. **Tradução Sensorial do Desfecho:**
   - O tradutor invoca `NarrativeSceneTranslator.translateIncidentResolved(resolutionResult, state)`.
   - A crônica do desfecho é registrada em `sessionLog.lastThingHappened` e exibida ao jogador.

## 7. Segurança Contra Mutações Produzidas por LLM

Para garantir que a LLM nunca influencie o estado mecânico:
1. **Isolamento de Tipagem:** A interface `IncidentNarrativeResponse` contém exclusivamente strings de texto narrativo (`narration`). Não existem campos para mutações, deltas numéricos ou alterações de estado.
2. **Filtro de Descarte:** Qualquer campo desconhecido retornado pelo JSON do modelo é descartado na desserialização.
3. **Imutabilidade Mecânica:** O `CampaignState` atualizado é produzido **exclusivamente** pelo `EventProcessor` antes de qualquer chamada à LLM.
4. **Proteção contra Injeção de Prompts:** Todo texto do jogador é envelopado em delimitadores estruturados e tratado como dado não-confiável de leitura.

---

## 8. Determinismo e Replay

- **Independência de Replay:** A reconstrução histórica e o replay determinístico (como os 10 snapshots de calibração ou a suíte de 520 semanas do M13) são baseados exclusivamente nos registros do `eventStore` (`WEEKLY_TURN_RESOLVED` e `EVENT_RECORD_APPLIED`).
- **Narrativa Não-Crítica para Replay:** Diferenças na geração de texto da LLM não alteram nenhum byte do estado mecânico. Duas execuções com a mesma semente reproduzem exatamente os mesmos números de tesouro, comida, unidades e hashes mecânicos, independentemente da variação poética da LLM.
- **Execução Offline / Headless:** Em ambientes sem rede ou em testes automatizados, o motor opera com 100% de funcionalidade através do fallback procedural.

---

## 9. Estratégia de Save / Load

- **Persistência de Cenas Ativas:** A `activeScene` aberta é persistida de forma estruturada no campo `sessionLog.activeScene` do `CampaignState`.
- **Persistência de Crônicas:** O texto sensorial do último incidente resolvido é gravado em `sessionLog.lastThingHappened` para exibição na reabertura do save.
- **Proteção ao Carregar:** Ao carregar um save JSON contendo `sessionLog.lastThingHappened`, esse texto é utilizado puramente para renderização na interface visual, nunca sendo reprocessado como comando ou mutação mecânica.

---

## 10. Tratamento Robusto de Falhas

| Cenário de Falha | Comportamento da Camada Narrativa | Impacto no Estado Mecânico |
| :--- | :--- | :--- |
| **API Key ausente** | Ativa imediatamente o `ProceduralFallbackTranslator` | Zero. Mutações aplicadas normalmente. |
| **Timeout de Rede (12s)** | Aborta requisição e recorre ao fallback procedural | Zero. Mutações aplicadas normalmente. |
| **Resposta vazia / HTTP 500** | Registra aviso no log e usa fallback procedural | Zero. Mutações aplicadas normalmente. |
| **Tentativa de alucinação de regras** | O validador semântico ignora números alucinados | Zero. O estado segue o `EventProcessor`. |
| **Texto com termos metalinguísticos** | Sanitizador de texto limpa termos de metalinguagem | Zero. Estado preservado. |

## 12. Hard Gates M18.9-D

- **Hard Gate D-1:** Somente `EventProcessor` pode alterar `CampaignState`. A LLM não tem acesso de escrita.
- **Hard Gate D-2:** Falha completa de conexão com o Gemini não impede nem aborta a resolução mecânica da semana ou da cena.
- **Hard Gate D-3:** A resposta da LLM é restrita a conteúdo textual passivo (`IncidentNarrativeResponse`), sem estruturas mutacionais.
- **Hard Gate D-4:** O replay determinístico de campanhas produz hashes de estado estritamente idênticos, independentemente da ativação ou variação da LLM.
- **Hard Gate D-5:** O silêncio mecânico é estritamente preservado nas narrativas emitidas ao jogador.
