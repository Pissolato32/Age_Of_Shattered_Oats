- **Dependências:** `src/types.ts`, `src/domain/events/models.ts`, `src/domain/events/SceneResolver.ts`, `src/lib/narrativeLLM.ts`, `./IncidentNarrativeContracts.ts`.
- **Motivo:** Manter o `EventProcessor`, `SceneResolver` e `EmergentIncidentPipeline` 100% livres de dependências de rede e de LLM.

## 4. Contratos Tipados e Reutilização Canônica

```typescript
// src/domain/events/narrative/IncidentNarrativeContracts.ts
import type { DescriptionContext, WorldEventMagnitude, TimeCost } from '../models';

export interface MechanicalFacts {
  readonly eventId: string;
  readonly eventType: string;
  readonly magnitude: WorldEventMagnitude;
  readonly domain: string;
  readonly absoluteTurn: number;
  readonly timeCostSummary: string;
  readonly mutationsSummary: readonly string[];
  readonly resolutionEventId?: string;
  readonly choiceMade?: {
    readonly choiceId: string;
    readonly label: string;
    readonly outcomeSummary: string;
  };
}

export interface NarrativeChoicePrompt {
  readonly choiceId: string;
  readonly label: string;
  readonly descriptiveHint: string;
}

export interface IncidentNarrativeRequest {
  readonly kind: 'INCIDENT_OPENED' | 'INCIDENT_RESOLVED' | 'ATMOSPHERIC_INCIDENT';
  readonly mechanicalFacts: MechanicalFacts;
  readonly context: DescriptionContext;
  readonly environmentContext?: {
    readonly regionName?: string;
    readonly seasonName?: string;
    readonly weatherDescription?: string;
    readonly holdingType?: string;
    readonly presentAdvisors?: readonly Array<{ readonly name: string; readonly role: string }>;
  };
  readonly availableChoices?: readonly NarrativeChoicePrompt[];
}

export interface IncidentNarrativeResponse {
  readonly narration: string;
  readonly promptChoicesFormatted?: readonly {
    readonly choiceId: string;
    readonly formattedText: string;
  }[];
  readonly source: 'GEMINI' | 'PROCEDURAL_FALLBACK';
}
```

## 5. Fluxo de Execução e Fronteiras de Responsabilidade

```text
1. Engine Semanal
   └─► EmergentIncidentPipeline.resolveEmergentIncidents(...)
         ├─► Determina oportunidade via DeterministicEventRNG
         ├─► Cria EventRecord (EventRecordFactory com DescriptionContext canônico)
         └─► Se cena OPEN: define state.sessionLog.activeScene = scene

2. Tradução da Cena Aberta (Post-Processing)
   └─► IncidentNarrativeTranslator.translateIncidentOpened(eventRecord, state, llm)
         ├─► Extrai MechanicalFacts (read-only)
         ├─► Reutiliza DescriptionContext de eventRecord.descriptionContext
         ├─► Monta IncidentNarrativeRequest
         ├─► Dispara Gemini (com fallback procedural em timeout/erro)
         └─► Retorna IncidentNarrativeResponse (texto puro para UI)

3. Decisão do Jogador
   └─► Jogador seleciona choiceId fechado

4. Resolução Mecânica Canônica
   └─► SceneResolver.resolveSceneChoice(scene, choiceId, baseEvent, state)
         ├─► Valida escolha
         ├─► Cria resolutionEvent (resolutionEventId determinístico + causalParentEventId)
         ├─► EventProcessor.processEvent aplica mutações e grava no eventStore
         └─► Retorna SceneResolutionResult + nextState

5. Tradução do Desfecho (Post-Processing)
   └─► IncidentNarrativeTranslator.translateIncidentResolved(resolutionResult, baseEvent, nextState, llm)
         ├─► Extrai MechanicalFacts do desfecho
         ├─► Gera crônica sensorial da consequência
         └─► Atualiza sessionLog.lastThingHappened com a crônica gerada
```

## 6. Segurança Contra Mutações por LLM

- **Saída Estritamente Textual:** A interface `IncidentNarrativeResponse` transporta exclusivamente `narration: string` e formatações de exibição de escolhas. Não há passagem de objetos `CampaignState`, `EventMutation`, ou flags booleanas mecânicas.
- **Isolamento Total do Estado:** O `CampaignState` é clonado/imutável e modificado **exclusivamente** pelo `EventProcessor`. A resposta da LLM é descartada ou armazenada como texto descritivo em `sessionLog.lastThingHappened`.
- **Sanitização de Metalinguagem:** O sanitizador verifica e remove eventuais termos técnicos ou alucinações matemáticas antes de entregar o texto à UI.

---

## 7. Tratamento Robusto de Falhas

- **API Key Ausente:** Ativa imediatamente `buildProceduralIncidentNarrative(request)`.
- **Network Timeout (12.000 ms):** `AbortController` cancela a requisição e aciona `buildProceduralIncidentNarrative`.
- **Resposta HTTP 4xx/5xx / JSON Malformado:** Capturado no bloco `try/catch` e direcionado ao fallback procedural.
- **Tentativa de Injeção de Mutações no Texto:** O sistema ignora qualquer instrução contida no texto, pois nenhuma rotina do motor avalia texto livre como código executável.

---

## 8. Determinismo e Replay

- **Independência de Replay:** As simulações de replay (52 semanas do C4 e 520 semanas do M13) são 100% independentes do texto gerado pela LLM.
- **Determinismo do Fallback Procedural:** `buildProceduralIncidentNarrative` produz exatamente as mesmas strings com base nos fatos mecânicos e tags do incidente.
- **Não-Contaminação do `EventStore`:** O `EventStore` grava apenas `WEEKLY_TURN_RESOLVED` e `EVENT_RECORD_APPLIED` com metadados mecânicos numéricos e hashes determinísticos.

## 10. Hard Gates M18.9-D

- **Hard Gate D-1:** `EventProcessor` permanece como única autoridade mecânica; a LLM tem zero acesso de escrita ao estado.
- **Hard Gate D-2:** Falhas de rede ou indisponibilidade da LLM nunca travam a simulação nem invalidam a resolução mecânica.
- **Hard Gate D-3:** A resposta da LLM é restrita a `IncidentNarrativeResponse` (prosa passiva).
- **Hard Gate D-4:** Replay determinístico de campanhas produz hashes mecânicos idênticos independentemente da camada narrativa.
- **Hard Gate D-5:** O teste M13 de 520 semanas permanece inalterado e passa com 100% de sucesso.
