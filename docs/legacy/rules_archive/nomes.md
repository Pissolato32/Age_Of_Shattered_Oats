# PART 15: SPIRIT NAMING SYSTEM — Pages 69-72

## 15.1 Core Principle
Every tribal/nomadic person has two names: an **everyday name** (daily life) and a **spirit name** (received in ceremony, used only in sacred contexts). Each person also has **sacred colors**.

## 15.2 Everyday Names
Simple, practical names. Examples: River, Stone, Wolf, Birch, Cloud, Fern, Elk, Rain.

**Full introduction to a trusted ally:** "I am Temujin of the Borjigin. The herd-taker. My father was Yesugei. His father was Bartan. The line runs deep."
**Full introduction to kin:** "Brother." (Clan name implied, never spoken to outsiders)

## PART 16.9 — COMPLETE NAME GENERATION PROCESS

For each landed noble at world generation:

1. **Step 1 — Determine Region and Culture** — Use regional tables from Part 21
2. **Step 2 — Generate Given Name** — Roll 1d100 on appropriate regional table. If repeating a name within 3 generations of same house, add "the Younger/Elder" or generate again.
3. **Step 3 — Generate House Name** — Roll 1d100 on Geographic OR Legendary table (50/50 chance). Can combine with regional feature: "of [Local Landmark]"
4. **Step 4 — Optional Epithet** — 30% chance for starting epithet (young characters rarely have one). Roll on Epithet table. Epithet should reflect personality or known deed.
5. **Step 5 — Check for Duplicates** — Compare with existing generated names in the region. If exact match (Given + House), modify: Add "the Elder/Younger" if related; Add "of [Location]" if different holdings; Reroll given name if unrelated.
