# INTRIGA, ESPIONAGEM E CONSELHO — Parts 92-98

## PART 92: ESPIONAGE SYSTEM (Pages 218-222 + Per Patch 7.26)

### 92.1 Core Principle
Espionage used to discover secret grudges, learn ambitions, uncover betrayals, find future plots, expose weaknesses.

### 92.2 Assigning Spies
Assign to: specific house, specific location, specific person, general region.
Each spy has skill level (1-6) determined by recruitment quality, training, experience.

### 92.3 Spy Check — 1d6 + Spy Skill
| Roll | Result |
|------|--------|
| 1 | Spy is caught |
| 2 | False rumor discovered |
| 3 | Minor secret (gossip) |
| 4 | True secret discovered |
| 5 | Major secret discovered |
| 6 | Major secret + Evidence |

### 92.4 Evidence Quality
| Level | Description |
|-------|-------------|
| None | Word of mouth only |
| Weak | Circumstantial, single witness |
| Moderate | Documents, multiple witnesses |
| Strong | Signed documents, seals, incontrovertible proof |

### 92.5 Spy Consequences (on a roll of 1)
Roll 1d6:
| Roll | Result |
|------|--------|
| 1 | Executed publicly |
| 2 | Imprisoned |
| 3 | Turned into double agent |
| 4 | Forced confession |
| 5 | Used in propaganda |
| 6 | Escaped but exposed |

### 92.6 Chain Espionage
Spies may recruit other spies, creating networks:
- **+1** to all spy checks in that region
- Redundancy (if one spy caught, network continues)
- Broader coverage

### 92.7 Blackmail System — Modifiers
| Condition | Modifier |
|-----------|----------|
| You have evidence | +1 |
| Target has low public loyalty | +1 |
| Secret involves heir or ruler | +1 |
| Secret involves religion | +1 |
| Target is fanatical | -1 |
| Secret is already rumored | -1 |

### 92.8 Blackmail Attempt — Roll 1d6 + modifiers
| Roll | Outcome |
|------|---------|
| 1 | Backfires (they expose you) |
| 2 | Ignored |
| 3 | Partial compliance |
| 4 | Full compliance |
| 5 | Obedience for 1 month |
| 6 | Target secretly becomes your agent |

### 92.9 Blackmail Failure Consequences
Target's Opinion **-2**, possible retaliation, reputation as blackmailer spreads.

### 92.10 Secret Types & Effects
| Secret Type | Effect if Exposed |
|-------------|-------------------|
| Illegitimate child | -2 Reputation, potential claim |
| Secret affair | -1 Reputation, possible feud |
| Hidden debt | Creditors demand payment, -1 Opinion |
| Betrayal | -3 Reputation, blood feud possible |
| Heresy | Excommunication, religious war possible |
| Crime | Imprisonment, execution, or ransom |

### 92.11 Time Integration
- Basic intelligence: **1d6 weeks**
- Deep infiltration: **1d6 months**
- Network building: **1d6 months per level**

## PART 94: THE SCHEMER (Per Patch 7.26)

### 94.1 Core Principle
A Schemer is Patient (wait years/decades), Cunning, Unreadable, Dangerous. NOT Obvious, Forgiving, Satisfied, or Safe.

### 94.2 Trigger Condition — Vanishingly Rare
At start of each year, for every noble lord with a grudge, silent roll:
| Condition | Modifier |
|-----------|----------|
| Base chance | 0.5% |
| Grudge is against blood relative | +2% |
| Grudge has lasted 5+ years | +1% |
| Grudge has lasted 10+ years | +2% |
| Lord has lost land/family/title to grudge | +2% |
| Lord has been publicly humiliated | +1% |
| Lord is already a Schemer | Cannot trigger again |

**Final Chance:** 1d100 ≤ modified chance → gains Schemer trait. System does not announce.

### 94.3 The Schemer's Stats
| Attribute | Effect |
|-----------|--------|
| Patience | +2 to all long-term plot rolls (6+ months) |
| Cunning | +2 to espionage rolls, +2 to framing others |
| Unreadable | -2 to others' attempts to read their intentions |
| Grudge Multiplier | Grudge now permanent. Cannot be resolved by apology or restitution. |
| Network | Automatically gains 1d6 spies within 1 year (if none existed) |

### 94.4 The Schemer's Goal — Regional Destabilization
Each year, a Schemer activates **1d3** of the following plots:
| Plot | Effect |
|------|--------|
| Spread Lies | -1 Opinion between two random lords in the region |
| Blackmail | One minor lord becomes secretly loyal to Schemer |
| Sabotage Trade | One trade route disrupted (-50% income for 1d6 months) |
| Frame Noble | One lord accused of a crime (real or false) |
| Assassination Attempt | Target a noble (use Part 95) |
| Foment Rebellion | Peasants in one holding become restless (-1 loyalty) |
| Secret Alliance | Two lords secretly allied against a third (unknown) |
| Murder | Kill a minor noble (if assassination succeeds) |
| Theft | Steal important document/heirloom, use as leverage |

### 94.5 The Web
| Element | Description |
|---------|-------------|
| Spies | 1d6 informants across the region |
| Blackmailed Lords | 1d3 minor lords who owe them |
| False Friends | 1d3 lords who think the Schemer is an ally |
| Contingencies | 1d3 plans that trigger if discovered |
| Hidden Resources | 1d6 × 100 SD stashed in secret locations |

If discovered: does not confess, does not flee, activates contingencies (release secrets, hire assassin, plant evidence, disappear).

### 94.6 Regional Instability Track
Each successful plot increases instability by **1**. Each failed (discovered/thwarted) plot increases by **1d3**.
| Level | Effects |
|-------|---------|
| 1-2 | Minor rumors. -1 to trade. |
| 3-4 | Lords suspicious. -1 Opinion between all pairs. |
| 5-6 | Trade disrupted. -25% regional income. |
| 7-8 | Assassinations common. Roll 1d6 each month: on 1, a noble dies. |
| 9-10 | Open conflict. Civil war possible. Roll 1d6 each season: on 1-2, war breaks out. |

### 94.7 Detecting the Schemer
**Investigation Roll:** 1d6 + Recon Rating + Espionage vs **DC 15 + Schemer's Cunning**
| Result | Information Gained |
|--------|-------------------|
| Fail | No leads. The web holds. |
| Success | Identify one of Schemer's agents (spy, blackmailed lord) |
| Success by 5+ | Identify the Schemer themselves |
| Success by 10+ | Discover the full web (all agents, contingencies) |

### 94.8 Confronting the Schemer
| Action | Consequence |
|--------|-------------|
| If killed | All contingents activate simultaneously, 1d6 secrets revealed, instability increases by **2d6** |
| If imprisoned | Contingencies activate one by one over months. Escape possible. |
| If exiled | Schemer leaves... may return in years with new plans. |

### 94.9 Cultural Reactions to Schemers
| Culture | View |
|---------|------|
| Central Plains | Dishonorable, but privately respect cunning |
| Western Rivers | Practical — scheming is business by other means |
| Eastern Forests (Settled) | Uncomfortable — feels wrong |
| Eastern Forests (Tribal) | The ancestors weep |
| Southern Mountains | The mountain remembers — warning |
| Northern Snowlands | Respect — cold teaches patience |
| Nomad Steppe (Traditional) | Confused — why not just fight? |
| Nomad Steppe (Settled) | Cautious respect — do not trust it |

### 94.10 The Schemer's End — Possible Outcomes
| Outcome | Description |
|---------|-------------|
| Victory | Enemy destroyed, region in ruins. Sits alone, smiling. |
| Death | Killed by enemy, accident, own web. Region breathes — scars remain. |
| Madness | Consumed by paranoia. Sees plots everywhere. |
| Redemption | Rare. Someone reaches them. Almost impossible. |
| Disappearance | Vanishes. Web lives on. No one knows if dead or waiting. |

## PART 95: ASSASSINATION SYSTEM (Pages 227-233 + Per Patch 7.26)

### 95.1 Core Principle
Murder is a dishonorable last resort. Attempting murder creates Dishonor Risk if discovered.

### 95.2 Murder Plot Creation
```
MURDER PLOT
─────────────────────────────────────
Plotter: ___________________
Target: ___________________
Status: ☐ Planning ☐ Preparation ☐ Ready ☐ Attempted
Time Invested: ___ days
─────────────────────────────────────
```

### 95.3 Finding an Assassin
| Source | Cost | Reliability | Risk |
|--------|------|-------------|------|
| Criminal Network | 50-200 SD | Low (may betray) | High |
| Assassin Guild | 200-500 SD | High | Medium |
| The Fifty (if available) | Free (but attrition) | Very High | Low (to plotter) |
| Mercenary | 100-300 SD | Medium | Medium |
| Fanatic | Variable | Variable | Variable |

### 95.4 Cost of Assassination
| Security Level | Base Cost |
|---------------|-----------|
| Low (unprotected) | 50 SD |
| Medium (guards) | 150 SD |
| High (fortified) | 300 SD |
| Extreme (maximum security) | 500+ SD |

### 95.5 Plot Development Phase
Roll 1d6 each week:
| Roll | Result |
|------|--------|
| 1 | Plot discovered! Target knows. |
| 2-3 | Suspicion raised (+1 to target's security) |
| 4-6 | No issues |

### 95.6 Plot Exposure Risk
| Factor | Modifier to discovery roll |
|--------|---------------------------|
| Plotter has high reputation | -1 |
| Plotter is known enemy | +2 |
| Using guild assassin | -1 |
| Using criminal network | +1 |
| Target has spies | +1 per spy |

### 95.7 Assassination Attempt
**Roll 1d6 + Assassin Skill vs Target Security (DC 4-7)**
| Result | Outcome |
|--------|---------|
| Fail by 3+ | Assassin caught, confesses |
| Fail by 1-2 | Attempt fails, assassin escapes |
| Success | Target killed |
| Success by 3+ | Target killed, no evidence |

### 95.8 Assassin Fate (if caught, roll 1d6)
| Roll | Result |
|------|--------|
| 1 | Immediately executed |
| 2-3 | Talks under torture (reveals plotter) |
| 4-5 | Killed resisting arrest |
| 6 | Rescued by allies |

### 95.9 Blood Feud Trigger
If murder proven, victim's house gains a Blood Feud Claim:
```
BLOOD FEUD
─────────────────────────────────────
House A: ___________________
House B: ___________________
Cause: Murder of _______________
─────────────────────────────────────
```

### 95.10 Murder Cooldown
After successful assassination, target's house on high alert for **1d6 months**. Further attempts at that house suffer **-2**.

### 95.11 NPC Assassination Plots
NPCs may also plot assassinations — resolved same mechanics, hidden until success or discovery.

## PART 96: THE KINSLAYER'S CURSE (Per Patch 7.23)

### 96.1 Core Principle
Killing a blood relative (parent, child, sibling, spouse by marriage counts) → permanent trait: **KINSLAYER**. Cannot be changed — only endured, avenged, or forgotten (never). Redeemed (impossible).

### 96.2 The Kinslayer's Reputation Score
| Condition | Modifier |
|-----------|----------|
| Base Opinion with all who know | -3 (permanent) |
| Additional if kinslaying was for power | -2 |
| Additional if accidental | -1 (still cursed) |
| Additional if self-defense | 0 (but still cursed) |
| Additional if witnessed publicly | -2 |
| Additional if hidden but discovered | -3 |

**Minimum Opinion Cap:** No Kinslayer can have Opinion higher than **+1** with anyone who knows.

### 96.3 The Gods Remember
| Faith | Reaction |
|-------|----------|
| Crownbound Church | Excommunication. No burial in consecrated ground. Priests refuse last rites. |
| Ashen Covenant | +1 to fear, -3 to trust. |
| Silent Faith | Silence. You are dead to them. |
| Tribal Spirits | Ancestors wail. Never receive their guidance again. |
| Nomad Sky | Name removed from clan. You are wind. You are nothing. |

### 96.4 Cultural Views on Kinslaying
| Culture | Punishment | Accidental | Legacy |
|---------|------------|------------|--------|
| Central Plains | Exile or execution | Exile, monastery, penance | Name stricken, children watched |
| Western Rivers | Economic death, blacklist | Severe fines, public apology | No contracts, no loans, no trade |
| Eastern Forests (Settled) | Cast out, no aid, death if return | Year of silence, face tattoo | Name forgotten, family may change name |
| Eastern Forests (Tribal) | Immediate banishment | Still banished, but offerings left | Name never spoken, spirit wanders |
| Southern Mountains | Execution | Exile, year of wandering, hand brand | Place cursed, family watches children |
| Northern Snowlands | Cast out into winter | Trial of Frost (3 days, no shelter) | Shame lasts generations, names changed |
| Nomad Steppe (Traditional) | Exile with nothing | Still exile, but with horse and water | Name erased, clan moves on |
| Nomad Steppe (Settled) | Execution (settled) or exile (trad) | Prison (settled) or exile with supplies (trad) | Family chooses which law to follow |

### 96.5 Kinslaying and Inheritance
| Situation | Effect |
|-----------|--------|
| Kinslayer was next in line | Line passes to next eligible relative |
| Kinslayer has children | Children may inherit only if they publicly denounce parent |
| Kinslayer is already ruling | Rule considered illegitimate. Vassals may rebel. |
| Victim had no other heirs | Title goes to liege lord or nearest collateral line |
| Victim's spouse remarries | Children of new marriage take precedence |

**The Tainted Blood:** Some cultures believe kinslayer's children are also tainted.

### 96.6 Kinslaying Through Assassination
| Factor | Modifier |
|--------|----------|
| Discovery chance | +3 (servants talk, family notices) |
| Evidence left | Automatic (someone always knows) |
| Blood Feud trigger | Automatic, permanent, multi-generational |
| Reputation loss | -5 (minimum) |

If Discovered: Immediate blood feud with entire family. No negotiation. No ransom. No mercy. Plotter becomes most hated person in the region.

## PART 97: THE LORD'S COUNCIL (Per Patch 7.31)

### 97.1 Core Principle
Every great lord (Tier 4+) has a council. Six seats — representatives from the six most powerful minor houses sworn to him. Blood relatives sent to represent family interests. Expected to advise, lobby, obstruct.

### 97.2 Council Composition
| Seat | Representative | Family Role |
|------|---------------|-------------|
| First Seat | Most powerful minor house | Usually lord's brother or eldest son |
| Second Seat | Second most powerful | Cousin or trusted uncle |
| Third Seat | Third most powerful | Experienced family member |
| Fourth Seat | Fourth most powerful | Ambitious younger son |
| Fifth Seat | Fifth most powerful | Elder statesman |
| Sixth Seat | Sixth most powerful | Wildcard — varies by house |

### 97.3 Who Sits? Family Representatives
| Relation | Typical Role |
|----------|-------------|
| Brother | Trusted, speaks with lord's full authority |
| Cousin | Reliable, may have own ambitions |
| Uncle | Experienced, often wiser than the lord |
| Nephew | Young, eager, learning |
| Son (not heir) | Ambitious, seeking influence |
| Grandfather (rare) | Ancient, respected, speaks rarely |
| Mother (rare) | If she holds wealth or influence |
| Daughter (rare) | If she is the power behind the house |

### 97.4 Women on Council — Conditions
She holds significant personal wealth, commands trained men, is the power behind a weak lord, is last of her line, is exceptionally wise or cunning.

### 97.5 Council Powers
| Power | Description |
|-------|-------------|
| Advise | Lord may ask — or they may offer unbidden |
| Lobby | Members push for policies benefiting their houses |
| Obstruct | If united, they can delay or block action |
| Inform | They bring news from their regions |
| Judge | They watch the lord. If he falters, they remember. |
| Choose | If lord dies without clear heir, council may have voice |

**Unified Council:** All six agree → Lord chooses: Accept (+2 loyalty from all minor houses) or Reject (-1 loyalty, risk of obstruction).

### 97.6 Council Dynamics
| Dynamic | Effect |
|---------|--------|
| Allies | Two support each other. +1 to lobbying. |
| Rivals | Two oppose each other. -1 to council stability. |
| Feud | Members from feuding houses. Council may deadlock. |
| Faction | Three+ form voting bloc. Can dominate. |
| Outsider | One member isolated. May seek lord's favor. |

**Council Stability Track:**
| Score | Meaning |
|-------|---------|
| 1-3 | Constant infighting. -1 to all advice rolls. |
| 4-6 | Tense but functional. No modifier. |
| 7-9 | Cooperative. +1 to advice rolls. |
| 10 | Unified. Rare. Powerful. Dangerous to lord. |

### 97.7 Losing a Seat — Blood in the Water
- Reputation Loss: **-2** to house reputation
- Rival Houses: **+1** aggression
- Internal Strife: Family may blame representative
- Desperation: House may take risks
- Succession Questions: Is this house still worth allying with?

### 97.8 Council Sessions
| Session Type | Frequency | Purpose |
|-------------|-----------|---------|
| Regular Session | Weekly/Monthly | Routine business, reports, minor decisions |
| War Council | As needed | Military strategy, levies, supplies |
| Crisis Session | Emergency | Invasion, rebellion, lord's illness |
| Feast Session | Seasonal | Celebrations, marriages, announcements |

### 97.9 The Lord's Relationship with Council
| Approach | Effect |
|----------|--------|
| Listen | +1 stability |
| Ignore | -1 stability. May obstruct. |
| Play Favorites | Favored +1 loyalty, others -1 |
| Pit Them Against Each Other | Keeps them weak, but stability drops |
| Replace Members | Causes resentment |
| Abolish Council | Possible? Yes. Wise? No. Rebellion likely. |

### 97.10 Cultural Variations
| Culture | Practice |
|---------|----------|
| Central Plains | Formal. Six seats. Strict hierarchy. First Seat speaks first. |
| Western Rivers | Practical. Seats based on wealth. Merchants may sit. |
| Eastern Forests (Settled) | Less formal. Members roam, speak when moved. |
| Eastern Forests (Tribal) | No council. Elders speak for families. |
| Southern Mountains | Ancient. Seats hereditary — lose a seat, lose it forever. |
| Northern Snowlands | Circle. No head. Lord sits among them. All speak freely. |
| Nomad Steppe (Traditional) | No council. Khan's brothers and sons advise while riding. |
| Nomad Steppe (Settled) | Adapted. Six seats. Women may sit (steppe tradition). |

### 97.11 Generating a Council

**Step 1:** Select six most powerful/loyal minor houses.
**Step 2 — Determine Representative (1d6):**
| Roll | Representative |
|------|---------------|
| 1 | Lord's brother |
| 2 | Lord's cousin |
| 3 | Lord's uncle |
| 4 | Lord's nephew |
| 5 | Lord's son (not heir) |
| 6 | Special (grandfather, mother, daughter, etc.) |

**Step 3 — Determine Gender if Special (1d6):**
| Roll | Outcome |
|------|---------|
| 1-4 | Male (standard) |
| 5 | Female (wealth/influence) |
| 6 | Female (exceptional — wise, cunning, warrior) |

**Step 4 — Generate Personality / Disposition (1d6):**
| Roll | Disposition |
|------|-------------|
| 1 | Loyal supporter |
| 2 | Pragmatic ally |
| 3 | Neutral |
| 4 | Skeptical |
| 5 | Ambitious (wants more for his house) |
| 6 | Hostile (secretly works against lord) |

**Step 5 — Relationships Between Members (1d6 per pair):**
| Roll | Relationship |
|------|-------------|
| 1 | Blood allies (same faction) |
| 2 | Friendly |
| 3 | Neutral |
| 4 | Rivals |
| 5 | Feuding |
| 6 | Secret alliance against another |

### 97.12 Council and Succession
| Situation | Council Role |
|-----------|-------------|
| Clear heir exists | Council confirms, may advise regent |
| Disputed succession | Council may choose — or split, causing civil war |
| No heir | Council may elect new lord from among their houses |
| Lord assassinated | Council investigates, may seek vengeance |

Council Election: New lord owes them. Seats become permanent. Power shifts.

## PART 98: THE PLAYER ON COUNCIL (Per Patch 7.32)

### 98.1 Players as Council Members
Player holding land as minor lord (Tier 2-3) may be granted a seat if among six most powerful/favored houses.

**Gaining a Seat:**
| Method | Description |
|--------|-------------|
| Inheritance | House already holds a seat |
| Favor | Liege grants due to exceptional service |
| Conquest | Defeat a house that holds a seat |
| Purchase | Rare, but coin can buy influence |
| Marriage | Marry into a house that holds a seat |

### 98.2 Player's Representative on Council
| Representative | Acceptance | Notes |
|---------------|------------|-------|
| Blood relative | Acceptable | Family speaks with family's voice |
| Spouse | Acceptable (if respected) | Especially if they hold influence |
| Retainer | Suspicious | "You send a servant to advise me?" |
| Mercenary | Unacceptable | "I do not take counsel from sellswords." |
| No one | Better than bad choice | Absence noted, but not insulting |

**The Great Lord's Reaction:**
| Lord's Personality | Reaction to Blood Relative | Reaction to Retainer |
|-------------------|---------------------------|---------------------|
| Patient, understanding | Accepts, -0 loyalty | -1 loyalty |
| Proud, traditional | -1 loyalty | -2 loyalty |
| Paranoid, suspicious | -2 loyalty | -3 loyalty |
| Pragmatic, focused | Accepts if competent | Accepts grudgingly |

### 98.3 War Council — The Lord's Second
| Who | Attendance Rule |
|-----|----------------|
| The great lord | Must attend |
| Minor lords | Expected to attend personally |
| Council members | Expected to attend personally |
| Representatives | Not allowed in War Council |

**Acceptable Second:**
| Second | Condition |
|--------|-----------|
| Blood relative | Must be of age and capable |
| Trusted commander | Must have proven themselves in battle |
| The lord's heir | Acceptable, even encouraged |

**Unacceptable Seconds:** Stewards (non-combatants), servants, anyone who has never fought, anyone the great lord does not know.

### 98.4 The Suspicion — Absence from War Council
| Situation | Reaction |
|-----------|----------|
| First absence, good reason | -1 loyalty, "See that it does not happen again." |
| Second absence, any reason | -2 loyalty, "Your lord tests my patience." |
| Third absence | -3 loyalty, possible loss of seat |
| Absence during crisis | Automatic -2 loyalty, possible accusations of cowardice |

### 98.5 Player as Second for Another Lord
| Role | Effect |
|------|--------|
| Represent your liege | +1 favor with liege, but you speak for him — carefully |
| Represent fellow minor lord | +1 relation with that house, but you carry their risk |
| Represent yourself? | Cannot — you are either the lord or the second |

If serving as Second: full voting/advising rights, treated as lord they represent, personally responsible for offense given. Perform well → gain reputation. Perform poorly → harm lord's standing.

### 98.6 Political Consequences of Absence
- Rumors spread (weak, ill, afraid)
- Rivals gain ground (lobby against you)
- Decisions made without you
- Policies that harm your interests may pass
- Loyalty drops — liege wonders if you are committed
- Seat at risk — another house may claim your place

**Missed Sessions in a Row:**
| Missed Sessions | Effect |
|----------------|--------|
| 1 | -1 opinion from liege |
| 2 | -2 opinion, rivals +1 to lobbying |
| 3 | -3 opinion, liege may demand explanation |
| 4+ | Seat may be declared vacant; roll 1d6: 1-3 = lose seat |

### 98.7 Cultural Variations on Attendance
| Culture | View on Attendance | View on Seconds |
|---------|-------------------|-----------------|
| Central Plains | Personal attendance expected. Absence is weakness. | Barely tolerated. Blood relatives only. |
| Western Rivers | Practical. Send someone competent. | Acceptable if competent. Suspicion if incompetent. |
| Eastern Forests (Settled) | Preferred, but understood. | Acceptable. |
| Eastern Forests (Tribal) | No councils. | N/A. |
| Southern Mountains | Ancestors watch. Attend or dishonor your line. | Blood only. No exceptions. |
| Northern Snowlands | Attend if you can. If not, send someone who can fight. | Seconds must be warriors. |
| Nomad Steppe (Traditional) | No councils. | N/A. |
| Nomad Steppe (Settled) | Attendance valued, but understood. | Acceptable if capable. |
